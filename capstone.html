Capstone Project

DEVELOPMENT OF A SMART PLASTIC BOTTLE DISPOSAL SYSTEM WITH PHONE CHARGING REWARDS FOR CITY OF MALABON UNIVERSITY.

A smart recycling system designed to encourage proper plastic bottle disposal by providing phone charging rewards to students of City of Malabon University.

01 / Overview

Project Overview

The Development of a Smart Plastic Bottle Disposal System with Phone Charging Rewards for City of Malabon University aims to address plastic bottle waste on campus by encouraging proper disposal through a technology-based solution. The project focuses on developing a smart disposal system that detects plastic bottle insertion and provides mobile phone charging time as a reward. By combining waste management with a practical incentive, the system aims to encourage students to participate in proper waste disposal and develop more environmentally responsible habits.

The project integrates hardware components, sensors, and embedded programming to automate bottle detection and connect the disposal process with the phone charging reward mechanism. It is designed to support the university’s environmental sustainability efforts while promoting the use of technology to address waste management challenges. Through this initiative, the project seeks to provide a practical and engaging approach to reducing improperly discarded plastic bottles and encouraging sustainable practices within the CMU community.

02 / System

System Design

02.1

System Overview

The Smart Plastic Bottle Disposal System aims to encourage proper plastic bottle disposal at City of Malabon University by offering phone charging time as a reward. The system uses sensors to detect and evaluate inserted objects before accepting a bottle and granting the corresponding charging time. It combines Arduino-based hardware, embedded programming, and a monitoring dashboard to manage bottle detection, reward allocation, and system data. By connecting responsible waste disposal with a practical incentive, the project supports the university's environmental sustainability efforts.

02.2

Hardware Components

The system uses an Arduino board to process sensor inputs and control the disposal and charging processes. IR sensors detect the presence and height of inserted objects, while a load cell measures their weight to help determine whether an object meets the bottle acceptance criteria. A capacitive proximity sensor helps identify metal objects, such as tin cans, for rejection.

The charging circuit includes a charging module, an INA219 current sensor, a step-down converter, and a relay module. These components support phone charging, monitor current consumption, and control the power supplied to the charging output. The disposal unit's physical structure and electronic housing hold the components in place and support the operation of the system.

02.3

Software and Control Logic

The system uses C++ for the Arduino's embedded logic, while JavaScript and Node.js handle communication between the Arduino and a connected computer. PHP is used to develop the monitoring dashboard, which allows an administrator to view system data when a computer is connected to the system.

During bottle detection, the IR sensors detect the presence and height of an inserted object. The load cell measures its weight, and the capacitive proximity sensor helps identify metal objects. The system processes these sensor inputs to determine whether the object meets the acceptance criteria. Once a bottle is accepted, its data is recorded and the corresponding phone charging time is awarded.

The charging system uses an INA219 current sensor to monitor electrical current and determine whether a phone is drawing power. The reward timer runs while the system detects active charging and pauses when no charging current is detected. This allows the user to use the remaining charging time without consuming it when no phone is charging.

When the remaining charging time reaches zero, the Arduino controls a relay module to disconnect the power supplied to the step-down converter that provides the charging output. This prevents further charging through the system until additional charging time is available.

02.4

System Workflow

The process begins when a user inserts a plastic bottle into the disposal unit. The system uses multiple sensors to evaluate the object's presence, height, weight, and possible metal content. If the object meets the system's acceptance criteria, the bottle is accepted, its data is recorded, and the corresponding phone charging time is awarded.

The user can then connect a phone to the charging output and use the available charging time. The INA219 monitors current consumption so the timer runs only while charging is detected. When no charging is detected, the timer pauses. Once the remaining time reaches zero, the relay disconnects the charging output, ending the reward cycle.
